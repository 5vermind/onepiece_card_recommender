# Patch Notes — v1.3.0 (2026-06-10)

## OP-13 메타 반영 업데이트

이번 업데이트는 추천 기준을 **OP-13 환경**으로 옮긴 패치입니다.  
기존 덱을 없애지는 않고, 지금 메타에서 밀려난 덱은 **Tier Out**으로 남겨두었습니다.

---

## 뭐가 바뀌었나요?

### 1. OP-13 주요 덱을 추가했습니다

새로 반영한 핵심 덱은 아래와 같습니다.

- 흑 이무
- 적청 에이스
- 적자 골 D. 로저
- 적흑 사보
- 녹자 림
- 황 보니
- 적녹 루피

OP-13에서 자주 언급되는 이무·에이스·녹 조로 중심 메타를 기준으로 정리했습니다.

### 2. 티어를 OP-13 기준으로 다시 잡았습니다

현재 추천 기준은 아래처럼 정리했습니다.

| 티어     | 덱                                                                         |
| -------- | -------------------------------------------------------------------------- |
| S        | 흑 이무, 적청 에이스, 녹 조로                                              |
| A        | 녹 보니, 적자 로저, 청자 루피, 적흑 사보, 자 루피, 녹자 림, 녹청 조로/상디 |
| B        | 적 레일리, 황 보니, 흑 티치                                                |
| C        | 녹자 루피, 적녹 루피                                                       |
| Tier Out | 기존 OP-11/OP-12 중심 비주류 덱들                                          |

### 3. 기존 덱은 삭제하지 않았습니다

이전 버전의 덱들은 그대로 남겨두었습니다.  
다만 OP-13 기준으로 메타권에서 멀어진 덱은 `Tier Out`으로 표시됩니다.

그래서 결과 화면에서 여전히 전체 순위로 볼 수는 있지만, 보통은 OP-13 활성 덱이 먼저 추천됩니다.

### 4. 추천 점수도 OP-13에 맞게 조정했습니다

`Tier Out` 덱은 취향이 아주 잘 맞을 때만 올라오도록 점수 페널티를 넣었습니다.  
예전 덱을 숨기기보다는, “남겨두되 현재 메타 덱을 먼저 보여주는” 쪽으로 맞췄습니다.

### 5. 화면 문구를 OP-13 기준으로 바꿨습니다

홈, 퀴즈 설명, 결과 공유 이미지 쪽에 남아 있던 OP-12 문구를 OP-13 기준으로 정리했습니다.

---

## 이번 버전에서 추천 흐름은 이런 느낌입니다

- 대회 지향이면 이무, 에이스, 녹 조로가 먼저 보이기 쉽습니다.
- 카운터나 취향을 고르면 보니, 자 루피, 사보, 림 같은 덱도 올라옵니다.
- 예전 덱은 완전히 빠지지 않고 Tier Out으로 남아 있습니다.
