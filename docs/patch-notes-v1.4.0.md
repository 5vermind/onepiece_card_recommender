# Patch Notes — v1.4.0 (2026-08-14)

## 한국 OP-14 현행 메타 업데이트

추천 기준을 **한국 OP-14 전체 카드풀**로 확장했습니다. 기존 OP-13 + EB-03 덱과
OP-14 신규·복귀 덱을 하나의 현행 추천 순위에서 비교하며, 별도의 출시 예정 미리보기는
제거했습니다.

---

## 뭐가 바뀌었나요?

### 1. OP-14 추천 목록을 현행 기준으로 통합했습니다

- OP-14 신규 리더 7종을 정식 추천 순위에 편입했습니다.
- OP-14 지원으로 다시 성과를 낸 **적녹 로**를 B티어 숙련자용 덱으로 추가했습니다.
- OP-14 현행 경쟁력이 낮은 벨로 베티, 적 조로, 황 보니, 레일리, 조로/상디, 리무,
  푸딩을 추천 목록에서 제외했습니다.
- 적청 비비 등 EB-03 덱도 OP-14 카드풀 안에서 함께 비교합니다.
- 모든 추천 덱에 핵심 카드, 강점, 약점, 매치업, 실전 팁을 제공합니다.

현재 주요 티어는 다음과 같습니다.

| 티어 | 덱                                                                                     |
| ---- | -------------------------------------------------------------------------------------- |
| S    | 흑 이무, 적청 에이스, 녹 미호크, 청황 보아 행콕                                        |
| A    | 청자 루피, 청황 나미, 녹 조로, 적자 로저, 적흑 사보, 적청 비비, 청 징베, 자 도플라밍고 |
| B    | 녹자 루피, 녹 보니, 적녹 루피, 적녹 로, 흑 크로커다일, 흑황 모리아                     |
| C    | 흑 티치, 적 로                                                                         |

### 2. 적녹 로의 OP-14 복귀를 반영했습니다

OP01 적녹 로는 OP14-013 루피와 OP14-016 X.드레이크를 얻어 슈퍼노바 전개 축의
일관성이 높아졌습니다. 영문권 OP-14.5 지역 대회에서 5위·7위를 포함한 복수 입상 기록이
확인되지만 전체 점유율은 아직 제한적이므로, 최상위권이 아닌 **B티어 다크호스**로
보수적으로 반영했습니다.

- 5면을 채운 뒤 공격을 마친 저코스트 캐릭터를 5코스트 전력으로 교체합니다.
- OP12 보니의 드로우, 캐번디시의 DON!! 재활성화, OP-14 슈퍼노바 지원을 연결합니다.
- 광역·연속 제거로 5면 조건이 끊기면 리더 효과의 템포가 크게 낮아집니다.
- 시퀀싱과 복구용 손패 보존이 모두 필요해 난이도와 구축 비용을 높게 책정했습니다.

### 3. 청자 루피와 주요 덱의 매치업 디테일을 보강했습니다

일본 13.5탄 대회 공략을 중심으로 정리했던 청자 루피의 상성에는 이무를 포함했고,
서로를 언급하는 주요 매치업의 유리·불리 방향도 교차 확인했습니다.

- 미세 불리: 흑 이무
- 미세 유리: 적청 에이스, 녹 조로
- 유리: 적흑 사보, 청황 나미
- 불리: 적자 로저
- 매우 불리: 녹 보니

표준 리스트나 충분한 표본이 없는 매치업은 단정하지 않고 `표본 부족` 또는 전략 유형
기준으로 표시합니다.

### 4. OP-14 신규 리더 7종을 정식 추천합니다

다음 덱은 더 이상 `출시 예정` 미리보기로 분리되지 않습니다.

- 적 로
- 녹 미호크
- 청 징베
- 청황 보아 행콕
- 자 도플라밍고
- 흑 크로커다일
- 흑황 모리아

신규 리더와 적녹 로를 기존 덱과 같은 방식으로 채점해 사용자의 플레이 성향에 따라
상위 추천에 노출합니다.

### 5. 화면의 기준 문구를 OP-14로 통일했습니다

- 결과 화면의 별도 `COMING SOON` 영역과 출시 예정 배지를 제거했습니다.
- 홈, 결과, 공유 이미지, 메타데이터의 카드풀 표기를 OP-14로 통일했습니다.
- 추천 이유도 OP-14 현행 티어를 기준으로 표시합니다.
