# Patch Notes — v1.4.0 (2026-08-14)

## 한국 OP-13 + EB-03 현행화 및 OP-14 미리보기

이번 업데이트는 추천 기준을 **한국 OP-13 + EB-03 카드풀**로 확장하고, 출시 예정인
**OP-14 신규 리더 7종**을 별도 미리보기로 제공하는 패치입니다.

현행 덱과 출시 예정 덱을 섞어 추천하지 않으며, 결과 화면에서 각각 분리해 확인할 수 있습니다.

---

## 뭐가 바뀌었나요?

### 1. EB-03 반영 추천 목록을 새로 정리했습니다

- 적청 비비와 자황 푸딩 등 EB-03 환경 덱을 추가했습니다.
- 청황 나미, 청자 루피 등 기존 덱의 EB-03 핵심 카드와 운영법을 보강했습니다.
- 현행 추천 덱마다 핵심 카드, 강점, 약점, 매치업, 실전 팁을 제공하도록 정리했습니다.

현재 주요 티어는 다음과 같습니다.

| 티어 | 덱                                                                                        |
| ---- | ----------------------------------------------------------------------------------------- |
| S    | 흑 이무, 적청 에이스                                                                      |
| A    | 청자 루피, 청황 나미, 녹 조로, 적자 로저, 적흑 사보, 적청 비비                            |
| B    | 녹자 루피, 적황 베티, 녹 보니, 적 레일리, 녹청 조로/상디, 녹자 리무, 적녹 루피, 자황 푸딩 |
| C    | 적 조로, 흑 티치, 황 보니                                                                 |

### 2. 청자 루피의 13.5탄 매치업을 재검토했습니다

일본 OP-13 + EB-03에 해당하는 13.5탄 대회 공략을 우선해 상성을 다시 정리했습니다.

- 미세 불리: 흑 이무
- 미세 유리: 적청 에이스, 녹 조로
- 유리: 적흑 사보, 청황 나미
- 불리: 적자 로저
- 매우 불리: 녹 보니

8코스트 로저, 9코스트 미호크, 레드 록을 중심으로 핵심 카드와 멀리건·선후공 운영 팁도
현행형으로 수정했습니다.

### 3. 주요 덱의 유불리를 서로 맞춰 정리했습니다

- 이무·에이스·녹 조로·녹 보니·로저·사보·티치 등 OP-13 주요 덱의 상성을 교차 확인했습니다.
- 서로를 동시에 언급하는 매치업은 한쪽이 유리면 반대쪽은 불리하도록 방향을 일치시켰습니다.
- 표준 리스트나 충분한 표본이 없는 녹자 루피·적녹 루피는 단정적인 평가 대신
  `표본 부족`으로 표시합니다.

### 4. OP-14 신규 리더 7종을 미리 볼 수 있습니다

출시 예정 덱은 현행 순위와 분리된 `OP-14 추천 미리보기` 영역에 표시됩니다.

- 적 로
- 녹 미호크
- 청 징베
- 청황 보아 행콕
- 자 도플라밍고
- 흑 크로커다일
- 흑황 모리아

각 덱에는 `OP-14 출시 예정` 배지가 표시되며, 해외 선행 환경 기반 평가는 한국 출시 후
변경될 수 있습니다.

### 5. 추천 결과 화면을 더 명확하게 바꿨습니다

- 현행 카드풀과 출시 예정 카드풀을 별도로 채점합니다.
- 현행 추천 전체 순위와 OP-14 미리보기 전체 목록을 각각 펼쳐 볼 수 있습니다.
- 홈, 결과, 공유 이미지의 기준 문구를 OP-13 + EB-03 및 OP-14 예정 환경에 맞췄습니다.
