# Patch Notes — v1.4.0 (2026-08-14)

## 한국 OP-14 현행 메타 업데이트

추천 기준을 **한국 OP-14 전체 카드풀**로 확장했습니다. 기존 OP-13 + EB-03 덱과
OP-14 신규·복귀 덱을 하나의 현행 추천 순위에서 비교하며, 별도의 출시 예정 미리보기는
제거했습니다.

---

## 뭐가 바뀌었나요?

### 1. OP-14 추천 목록을 현행 기준으로 통합했습니다

- OP-14 신규 리더 7종을 정식 추천 순위에 편입했습니다.
- OP-14 지원으로 다시 성과를 낸 **적녹 로**를 B티어 숙련자용 덱으로 추가했습니다.
- OP-14 현행 경쟁력이 낮은 벨로 베티, 적 조로, 황 보니, 레일리, 조로/상디, 리무,
  푸딩을 추천 목록에서 제외했습니다.
- 적청 비비 등 EB-03 덱도 OP-14 카드풀 안에서 함께 비교합니다.
- 모든 추천 덱에 핵심 카드, 강점, 약점, 매치업, 실전 팁을 제공합니다.

현재 주요 티어는 다음과 같습니다.

| 티어 | 덱                                                                 |
| ---- | ------------------------------------------------------------------ |
| S    | 흑 이무, 적청 에이스, 녹 미호크, 청황 보아 행콕                    |
| A    | 청자 루피, 청황 나미, 녹 조로, 적흑 사보, 청 징베, 자 도플라밍고   |
| B    | 녹 보니, 적녹 루피, 적녹 로, 청자 상디, 흑 크로커다일, 흑황 모리아 |
| C    | 흑 티치, 적 로, 녹자 루피, 적청 비비, 적자 로저                    |

### 2. 비비·녹자 루피·적녹 루피·로저·청자 상디의 OP-14 티어를 다시 검증했습니다

EB-04가 포함된 OP-14.5 성적은 배제하고 영문권 `OP14` 포맷과 일본 순수 OP-14 대회만
비교했습니다.

- **적청 비비: A → C** — OP-14 공개 집계에 입상 기록이 없어 오프메타 잠재력만 반영했습니다.
- **녹자 루피: B → C** — OP-14 입상 기록은 없으며, OP-14.5 4위·17위 리스트가 EB-04
  카드를 사용하지 않았다는 점은 향후 가능성을 보여 주는 보조 자료로만 반영했습니다.
- **적녹 루피: B 유지** — 38포인트·2.26%로 9위이며, 라스베이거스 3위와 월드 파이널
  5위의 고점이 있지만 표본이 작아 A티어까지 올리지는 않았습니다.
- **적자 로저: A → C** — 확인되는 6회 입상은 모두 OP-13이며 OP-14 기록은 없습니다.
- **청자 상디: Out → B** — 약 1%의 사용률로 일본 도쿄 제2 에리어 47위를 완주하고
  플래그십 우승도 기록했으며, 당시 일본 메타 예상에서 Tier2로 분류됐습니다. 영미권
  OP-14 공개 입상과 충분한 표본은 없어 A가 아닌 숙련자용 다크호스로 평가했습니다.

다섯 덱의 설명·핵심 카드·매치업 표본 주의 문구도 같은 기준으로 갱신했습니다.

### 3. 적녹 로의 OP-14 복귀를 반영했습니다

OP01 적녹 로는 OP14-013 루피와 OP14-016 X.드레이크를 얻어 슈퍼노바 전개 축의
일관성이 높아졌습니다. EB-04가 허용된 영문권 OP-14.5 대회의 입상 리스트가 EB-04 카드를
사용하지 않은 점은 보조 근거로만 활용했으며, 포맷 차이를 감안해 **B티어 다크호스**로
보수적으로 반영했습니다.

- 5면을 채운 뒤 공격을 마친 저코스트 캐릭터를 5코스트 전력으로 교체합니다.
- OP12 보니의 드로우, 캐번디시의 DON!! 재활성화, OP-14 슈퍼노바 지원을 연결합니다.
- 광역·연속 제거로 5면 조건이 끊기면 리더 효과의 템포가 크게 낮아집니다.
- 시퀀싱과 복구용 손패 보존이 모두 필요해 난이도와 구축 비용을 높게 책정했습니다.

### 4. 청자 루피와 주요 덱의 매치업 디테일을 보강했습니다

일본 13.5탄 대회 공략을 중심으로 정리했던 청자 루피의 상성에는 이무를 포함했고,
서로를 언급하는 주요 매치업의 유리·불리 방향도 교차 확인했습니다.

- 미세 불리: 흑 이무
- 미세 유리: 적청 에이스, 녹 조로
- 유리: 적흑 사보, 청황 나미
- 불리: 적자 로저
- 매우 불리: 녹 보니

표준 리스트나 충분한 표본이 없는 매치업은 단정하지 않고 `표본 부족` 또는 전략 유형
기준으로 표시합니다.

### 5. OP-14 신규 리더 7종을 정식 추천합니다

다음 덱은 더 이상 `출시 예정` 미리보기로 분리되지 않습니다.

- 적 로
- 녹 미호크
- 청 징베
- 청황 보아 행콕
- 자 도플라밍고
- 흑 크로커다일
- 흑황 모리아

신규 리더와 적녹 로를 기존 덱과 같은 방식으로 채점해 사용자의 플레이 성향에 따라
상위 추천에 노출합니다.

### 6. 화면의 기준 문구를 OP-14로 통일했습니다

- 결과 화면의 별도 `COMING SOON` 영역과 출시 예정 배지를 제거했습니다.
- 홈, 결과, 공유 이미지, 메타데이터의 카드풀 표기를 OP-14로 통일했습니다.
- 추천 이유도 OP-14 현행 티어를 기준으로 표시합니다.
